# Task SaaS Frontend

This package contains the React user interface for Task SaaS. It handles authentication, protected navigation, and task management actions through the backend API.

For the complete setup and production guide, see the root [README](../README.md).

## Quick Start

1. Create a `.env` file and set `VITE_API_URL`.
2. Install dependencies with `npm install`.
3. Start the dev server with `npm run dev`.

## Scripts

- `npm run dev` - start the Vite dev server
- `npm run build` - type-check and build the production bundle
- `npm run lint` - run ESLint
- `npm run preview` - preview the built app locally

## Environment

- `VITE_API_URL` - backend base API URL, for example `http://localhost:5000/api`
